# 在庫・売上管理ツール

Windows での使い始め方を中心に説明します。  
※ 開発者向けの詳細は [TECHNICAL.md](TECHNICAL.md) を参照してください。

---

## このアプリでできること

* 商品マスタの登録・編集
* 在庫の入庫・出庫・調整（まとめて操作にも対応）
* 在庫履歴の確認・期間指定・印刷（ブラウザ版）
* 顧客ごとの売上入力・一覧
* 売上は **在庫数には影響しません**

**画面の出し方は 2 種類あります。**

| 種類 | 特徴 |
|------|------|
| **デスクトップ版** | いつものウィンドウアプリ（Tkinter） |
| **ブラウザ版** | Edge / Chrome などで `http://127.0.0.1:8765` を開く |

どちらも **同じデータファイル**（JSON）を読み書きします。同時に動かすと待ちが出るので、基本はどちらか一方の利用を推奨します。

## まず用意するもの（Windows・初回だけ）

### Python 3.10 以上

1. **Microsoft Store** で「Python 3.12」などを検索してインストール  
   **または** [python.org](https://www.python.org/downloads/) からインストーラーを取得
2. インストール時、可能なら **「Add python.exe to PATH」** にチェック

### 動作確認（任意）

コマンドプロンプトまたは PowerShell で:

```bat
python --version
```

`Python 3.xx` と出れば OKです。  
`python` でなく **`py`** だけ動く PC でも、このフォルダの `.bat` は自動で切り替えます。

## フォルダにある .bat ファイル（Windows・この 2 つだけ）

| ファイル | いつ使う？ |
|----------|------------|
| **setup.bat** | **最初に 1 回**。仮想環境（`.venv`）を作り、`requirements.txt` を入れる |
| **run.bat** | **いつもここから起動**。メニューでデスクトップ版 / ブラウザ版 / ブラウザ自動オープン / デスクトップショートカット作成を選ぶ |

コマンドラインから引数だけ渡すこともできます（ショートカット用）: `run.bat desktop` / `run.bat web` / `run.bat webopen` / `run.bat shortcut`

> **表示について:** `.bat` を実行したときのメッセージは、Windows の文字コードの都合で **英語** にしています（コメントも同様）。手順の説明はこの README が日本語です。

## 手順 A：.exe で配布する（開発者向け）

単体 `.exe` のビルド手順は **`TECHNICAL.md` の「Windows: 配布用 .exe のビルド」** にまとめています（PyInstaller を `setup.bat` 後の仮想環境で実行する流れです）。

ビルドして `_dist\inventory-sales-tool\` に配置した場合、データの保存場所は **`_dist\inventory-sales-tool\sales_inventory_tool.json`** です（`paths.py` の仕様）。

---

## 手順 B：Python のままデスクトップ版を試す

1. **setup.bat** をダブルクリック（初回だけ）
2. **run.bat** をダブルクリック → メニューで **1**（Desktop app）

データは **このフォルダ直下** の `sales_inventory_tool.json` に保存されます（`paths.py` の仕様）。

---

## 手順 C：ブラウザ版を使う

1. **setup.bat** をダブルクリック（未実行なら）

### デスクトップからワンクリックで起動＋ブラウザを開く（推奨）

1. **run.bat** を開き、メニューで **4**（Create desktop shortcut）を一度だけ選ぶ  
   - デスクトップに **Inventory Sales Tool Web** ができます（`run.bat webopen` を実行するショートカット）
2. 以降はそのショートカットをダブルクリック（サーバー用の黒い窓が開き、数秒後にブラウザが開きます）
3. 終了するときは **サーバー用の黒い窓を閉じる**（または Ctrl+C）

（ショートカットなしなら **run.bat** → **3**、または `run.bat webopen` でも同じ動きです。）

### 手動で URL を開く場合

1. **run.bat** → メニュー **2**（Web server only）
2. ブラウザで **http://127.0.0.1:8765**
3. 終了するときは **その黒い窓を閉じる**（または Ctrl+C）

### ポートが「使用中」と言われたとき

別のソフトが **8765** を使っています。コマンドプロンプトで:

```bat
set PORT=8766
```

を実行してから、**同じウィンドウ**で `run.bat` を起動すると（メニュー 2 または 3）、サーバーとブラウザの URL の両方に反映されます。

手で直す場合:

```bat
cd /d このフォルダのパス
.venv\Scripts\activate.bat
python -m web
```

## 使い方のヒント（共通）

### 最初に商品を登録する

* **デスクトップ版**: 在庫タブ → 商品マスタ  
* **ブラウザ版**: **商品** タブ

### 在庫を増やす・減らす

* **デスクトップ版**: 単発入出庫 / 一括入出庫  
* **ブラウザ版**: **入出庫** タブ（プレビュー付き）

### 売上

* **デスクトップ版**: 売上・顧客まわりのタブ  
* **ブラウザ版**: **売上** / **顧客** タブ

### テーマ・管理者モード（ブラウザ版）

* **設定** タブでテーマや管理者モード（商品の完全削除など）を切り替えられます。設定はブラウザの localStorage に保存されます。

## データの保存場所（整理）

| 起動の仕方 | JSON の場所の目安 |
|------------|-------------------|
| PyInstaller で作った exe（手順 A） | `_dist\inventory-sales-tool\sales_inventory_tool.json` |
| run.bat からソース実行（デスクトップ／Web） | フォルダ直下 `sales_inventory_tool.json`（カレントがプロジェクトルートのとき） |

**バックアップ**は該当する `sales_inventory_tool.json` をコピーするだけで大丈夫です。

Git に上げる場合、個人データの JSON はコミットしないでください（`.gitignore` 参照）。

## よくあるトラブル（Windows）

### 「Python が見つかりません」

* Python をインストールし直す  
* インストール後、**PC を一度再起動**してから `setup.bat` を再実行

### 黒い画面がすぐ消える

* エクスプローラーでフォルダを開き、アドレス欄に `cmd` と入力して Enter  
* 開いた窓で `setup.bat` または `run.bat` と入力して Enter  
  → メッセージが読めます

### ブラウザ版が開かない

* **run.bat**（Web サーバー用）の窓が閉じていないか確認  
* アドレスは **http://127.0.0.1:8765**（`https` ではない）  
* 会社 PC だとファイアウォールで弾かれることがあります

### デスクトップ版の画面が出ない

* **run.bat** → **1** から起動し、黒い窓にエラーが出ていないか確認  
* exe 利用の場合は `_dist\inventory-sales-tool\` 内の exe を同フォルダで実行してみる

### ブラウザ用のデスクトップショートカット（メニュー 4）が作れない

* **OneDrive** でデスクトップが移っている PC では、フォルダが `%USERPROFILE%\Desktop` に無いことがあります。**run.bat** は `OneDrive\Desktop` と PowerShell の「デスクトップ」パスも順に試します。  
* 会社 PC で **PowerShell が制限**されていると、最後の手段まで辿り着けず失敗することがあります。その場合は `run.bat webopen` を手で実行するか、ショートカットを手作りしてください。
